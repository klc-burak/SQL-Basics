# SQL-Basics

This repository focuses on SQL fundamentals and is not tied to a specific database, but examples are compatible with PostgreSQL, MySQL, SQL Server, and SQLite.

A comprehensive collection of fundamental SQL examples that demonstrate how to query, manage, and manipulate databases effectively.  
Each folder focuses on a specific SQL concept — from basic syntax and filtering to joins, aggregate functions, and database operations.

---

## Overview

This repository is designed as a step-by-step guide for anyone who wants to learn or revise SQL fundamentals.  
Each numbered directory contains an `Example.sql` file illustrating one core SQL concept with simple, readable queries.

Whether you're a beginner learning SQL for the first time or revisiting database concepts, this collection serves as a practical reference.

## How to Use

1. Open any `Example.sql` file in your SQL environment (e.g., MySQL Workbench, SQL Server, PostgreSQL, or SQLite).
2. Review the comments and SQL statements.
3. Run the queries step-by-step to observe how each command behaves.
4. Experiment by modifying the examples to reinforce your understanding.

---

## Topics Covered

- SQL Syntax & Query Structure
- Data Retrieval (`SELECT`, `WHERE`, `ORDER BY`)
- Logical Operators (`AND`, `OR`, `NOT`)
- Data Manipulation (`INSERT`, `UPDATE`, `DELETE`)
- Aggregate Functions (`SUM`, `AVG`, `COUNT`, etc.)
- Filtering and Grouping (`GROUP BY`, `HAVING`)
- Joins (`INNER`, `LEFT`, `RIGHT`, `FULL`, `SELF`)
- Constraints & Keys (`PRIMARY`, `FOREIGN`, `UNIQUE`, `CHECK`)
- Database Management (`CREATE`, `ALTER`, `DROP`)
- Views, Procedures, and Indexes
- SQL Security & Injection Prevention
